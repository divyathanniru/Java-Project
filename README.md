# Java-Project: Hospital Emergency Room and Triage System

## What is This?

This is a simple Java program that automates patient triage in a hospital emergency room. Instead of manually tracking patients on paper, this system takes the triage level of each patient and automatically works out which category must be treated first. It's fast, accurate, and prevents mistakes.

## How to Use

1. Run the program: java ERTriageSystem
2. Enter how many patients have arrived
3. For each patient, select the triage level (1, 2, or 3)
4. The system shows the triage report and which category to treat first

## What It Does

- Takes patient triage levels through the console
- Checks if levels are valid (1-3 range)
- Counts patients in each category automatically
- Finds and displays the category to treat first (Critical, Urgent, Non-Urgent)
- Shows the patient count for each category and the busiest category

## What Java Concepts Are Used

- CO1 (Basics): Variables, arrays, Scanner input, data types
- CO2 (Loops & Conditions): For loops, if-else statements, validation
- CO3 (Arrays & Algorithms): Array operations, finding maximum values
